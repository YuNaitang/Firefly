# 关于我

你好呀~这里是鱼鼐棠（Yu Naitang），自称底栖类生命，经常默默的看着，或许可以在科技、新闻、生活、搞笑等等地方遇到我哦。

你可以叫我小鱼，大多数国内好友这么称呼我。(*^▽^*)

==内向害羞不喜欢主动说话精力有限==

一个大学生，居住在河南。欢迎来河南玩哦！这边有很多美食美景，还有很深厚的历史，如果想听故事的话，可以听一宿都听不完呢！ヾ(≧▽≦*)o

一个计算机爱好者，喜欢以编程为手段完成许多有意思的事。不过代码写的很烂就是啦...有在努力学习哦！(*/ω＼*)

一个习惯于碎碎念的人，打字很慢，脑子很笨，所以会考虑很久才会发出来消息。才不是不想和你说话，请给我一点打字的时间啦...o(TヘTo)

一个单机电子游戏玩家，经常活跃在原神，以及一些奇奇怪怪的小游戏中。不玩竞技类游戏，因为真的很菜。o(>ω<)o

一个喜欢看动漫的人，喜欢萌系、可爱向、治愈向的番~loli控会说自己不是loli控吗？o(*￣︶￣*)o

一个看风景的人，如果在风景图遇到我，或许可以一起挂机（？）╰(*°▽°*)╯

秉承早期互联网精神，遵守网络礼仪，如果你报以恶意，请自觉走开。拒绝和抵制人身攻击、地域黑、黄赌毒。╰（‵□′）╯

## 🛠️ 关于本站

这个网站使用 **Astro** 框架构建，采用了 [Firefly](https://github.com/CuteLeaf/Firefly) 模板，Firefly 是基于 [Fuwari](https://github.com/saicaca/fuwari) 的二次开发。

**Firefly** 是一款基于 Astro 框架和 Fuwari 模板开发的清新美观且现代化个人博客主题模板，专为技术爱好者和内容创作者设计。该主题融合了现代 Web 技术栈，提供了丰富的功能模块和高度可定制的界面，让您能够轻松打造出专业且美观的个人博客网站。
