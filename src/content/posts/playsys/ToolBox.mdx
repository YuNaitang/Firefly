## ⚡️ 快速恢复命令 (Zero-Dependency Setup)

如果你只想快速恢复，无需一个个点击下载。我使用 **Winget** (Windows) 进行批量安装。

将以下代码块复制到终端，即可一键安装 90% 的核心工具：

```bash
# Windows (Winget) 示例
winget install -e --id Git.Git
winget install -e --id Microsoft.VisualStudioCode
winget install -e --id Obsidian.Obsidian
# ... 更多见下方清单
```

```bash
# macOS (Homebrew) 示例
brew install git node python
brew install --cask visual-studio-code google-chrome
```

> 💡 **配置文件同步提示**：大部分软件的配置（如 VS Code、Zsh）我通过 **GitHub Dotfiles** 仓库同步，克隆后执行 `./setup.sh` 即可恢复所有快捷键与主题。

## 📂 分类目录

### 1. 开发与编程 (Development)
*这类工具决定了我写代码的效率。*

| 软件名称 | 用途 | 安装指令 (Winget) | 配置文件位置/备注 |
| :--- | :--- | :--- | :--- |
| **Visual Studio Code** | 主编辑器 | `winget install Microsoft.VisualStudioCode` | 同步 GitHub 账号即可恢复插件 |
| **Git** | 版本控制 | `winget install Git.Git` | 全局配置 `.gitconfig` 需软链接 |
| **Node.js (LTS)** | 运行时 | `winget install OpenJS.NodeJS.LTS` | - |
| **Windows Terminal** | 终端模拟器 | `winget install Microsoft.WindowsTerminal` | 配置文件 `settings.json` 存于 OneDrive |

### 2. 网络与浏览器 (Browsers & Network)
| 软件名称 | 用途 | 安装指令 | 备注 |
| :--- | :--- | :--- | :--- |
| **Edge** | 主浏览器 | `winget install MIcrosoft.Edge` | 登录谷歌账户同步书签/密码 |
| **Clash Verge** | 网络代理 | `winget install ClashVerge.ClashVerge` | 配置文件订阅链接需手动填入 |

### 3. 系统增强与效率 (Utilities)
*这些是提升交互体验的小工具。*

- **PowerToys**：微软官方效率套件（含颜色选择器、分屏）。  
  `winget install Microsoft.PowerToys`
- **Everything**：极速文件搜索。  
  `winget install voidtools.Everything`
- **Ditto**：剪贴板历史管理。  
  `winget install Ditto.Ditto`
- **Snipaste**：截图贴图工具。  
  `winget install Snipaste.Snipaste`

### 4. 写作与笔记 (Writing)
- **Obsidian**：知识库管理（配合 iCloud/OneDrive 同步库）。
- **Typora**：轻量级 Markdown 编辑器（用于快速预览）。
- **花筏**：轻量笔记软件，随手编辑，用于替代Typora

### 5. 通讯与多媒体 (Communication)
- **WeChat / QQ**：日常沟通。
- **网易云音乐**：背景音乐。
- **Telegram**：沟通软件
- **ThunderBird**：邮件客户端

## 关键软件的、

光装软件没用，必须恢复设置。以下是我手动备份的关键路径：

### VS Code 插件列表恢复
登录`MIcrosoft` / `Github` 账号，我导出插件列表并存入 GitHub：
```bash
# 备份指令（已执行过）
code --list-extensions > vscode_extensions.txt

# 恢复指令（重装后运行）
cat vscode_extensions.txt | xargs -n 1 code --install-extension
```
